# 照片資料夾 📷

把每天的照片放進這個資料夾，網頁上那一天就會自動出現相簿，**不用改任何程式碼**。

## 命名規則

檔名格式：`MMDD_序號.jpg`

- `MM` = 月份兩位數（例：06）
- `DD` = 日期兩位數（例：06）
- 序號從 1 開始，連續編號（中間不能跳號，跳號後面的就不會顯示）

## 範例

6/6 那天的照片：

```
photos/0606_1.jpg
photos/0606_2.jpg
photos/0606_3.jpg
```

其他天：

| 日期 | 檔名 |
|------|------|
| 5/30 | 0530_1.jpg, 0530_2.jpg … |
| 5/31 | 0531_1.jpg … |
| 6/1  | 0601_1.jpg … |
| 6/4  | 0604_1.jpg … |

## 怎麼上傳（手機/電腦都可）

1. 打開 GitHub 上的這個 `photos` 資料夾
2. 點「Add file → Upload files」
3. 把照片拖進來，**先把檔名改成上面的格式**
4. Commit，幾分鐘後重新整理網頁就會看到照片

## 注意

- 目前只認 **.jpg**（如果是 .png/.heic，先轉成 .jpg）
- 每天最多顯示 30 張
- 照片建議先壓縮一下（手機原圖很大，會載比較慢）
